## Must-see elements (chrome contract)

1. **Calm teal framework** for the chapter/script chrome  
2. **Solid red / danger fill only on real T1 (112)**  
3. **T1 ≫ T2 ≫ T4** readable without relying on gore  
4. **T2 window labels** remain honest (gleichtags / ≤24–48 h / medizinisch-psychiatrisch) — not softened into „irgendwann“  
5. **SCOPE** geometrically outside TIME; title from C (`Grenze der eigenen Zuständigkeit`)  
6. **Imagery ban enforced:** no suicide methods, no strangulation/weapon/blood motifs, no dark „suicide art“, no sensational free-vision scenes, no stigmatizing portraits  
7. **No decorative nooses / weapons / means icons** even as „symbols“  
8. **Language:** DE pins from C only; no sensational wording beyond C  
9. **Form-meta ban** inside figures  
10. If tools shown: **„Orientierung, kein Ausschluss“** readable
