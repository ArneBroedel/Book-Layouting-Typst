## Learner context

- **Actor:** PT/HP Direktzugang; post-trauma / post-OP / cast patient with “Muskelkater” talk

## Learner job (one primary)

**recognize** (loge / limb + critical signs) + feed **stop**

**Primary job in one sentence:** Under scan stress, localize the osteofascial compartment problem (default: **vorderes Unterschenkelkompartiment**), bind the loud criteria cluster (disproportional pain · passive stretch · board-hard loge · pulses NOT excluding), and know **not** to elevate above heart or treat as MSK.

## Icon meaning (required — free-vision criteria graphics)

| pin / zone | drawing must show (not only caption) | must not show / mean |
|---|---|---|
| **Disproportionaler Schmerz** | Schmerz deutlich stärker als zur Verletzung passend (Blitz/intensity vs injury scale) | English-only „Pain out of proportion“ as sole print label; mild DOMS equivalence |
| **Passiver Dehnungsschmerz** | passiver Dehnungsreiz (Bsp. **Plantarflexion** → vordere US-Loge) as **exam finding** | forcierte **therapeutische** Dehnung as treatment measure |
| **Brettharte Loge** | prall-bretthartes Kompartiment / hard compartment surface | „normale Schwellung = ACS“; soft puffy edema only |
| **Pulse NOT excluding** | Pulse/Wellen **present** with Cave / strike / “schließt nicht aus” | „pulslos = ACS-Beweis“; „Puls da = Entwarnung“; green check on pulse |
| **Gips/Verband** (optional) | iatrogener Trigger; lockern/öffnen; Spaltung ≠ Ausschluss | „Gips ab = geheilt“ |
| **Anti-elevation** | Extremität **nicht** über Herzhöhe lagern (strike-through elevation) | Beinhochlagerung as standard first aid here |
| **Uhr / Stunden** | stundenkritische Ischämie / Eskalation über Stunden | invented countdown minutes or mmHg numbers |
| **CECS contrast** (optional chip) | belastungsabhängig, in Ruhe abklingend | CECS = green free-pass without Re-Triage note |
| **Anterior loge map** | osteofascial anterior compartment region marked | unlabeled pretty calf; all four compartments forced without C pins |
