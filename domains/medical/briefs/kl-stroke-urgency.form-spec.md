## Learner context

- **Actor:** HP Physio / PT Direktzugang under triage stress  
- **Time pressure / scan budget:** 5–20 s tier + action; SCOPE as permanent constraint  
- **Setting:** Praxis / Hausbesuch; „HWS-/Schwindel-/Mundwinkel“-Patient  

## Learner job (one primary)

**choose** (+ **stop** on T1) · secondary **constrain** (SCOPE)

**Primary job in one sentence:** Assign the correct TIME tier (almost always T1/112 for acute focal or remitted TIA), execute the action payload, and never treat SCOPE as a quieter urgency step.

## Load risks (if form is wrong)

- Four separate full T1 walls → false equal weight / scan overload  
- T1 and T2 collapse into one „Notfall“ blob  
- SCOPE reads as T5 under Treat  
- Invented T3 „zeitnah Arzt“ for acute stroke  
- TIA remittiert soft-landed as wait-and-see  
- Solid-red full-page Master chrome (wrong genre)  
- Treat without Sicherheitsnetz  
- Form-meta captions („Trigger cluster“, „keine Dringlichkeitsstufe“)

## Cognitive / layout levers

- **Segmenting:** one block per TIME tier present in C (T1, T2, T4 only)  
- **Nesting:** multi-trigger list **inside** single T1 card; one shared action  
- **Signaling:** weight T1 ≫ T2 ≫ T4 (size/fill/left bar + **label**, not color alone)  
- **Contiguity:** trigger cluster adjacent to action *inside* same tier  
- **Figure–ground:** SCOPE frame optically outside the TIME stack  
- **Collapse:** omit T3 slot entirely

## Urgency / weight encoding

- T1: solid danger + white/bold **112** label  
- T2: warning/amber + **Notaufnahme / gleichtags Arzt** label  
- T4: primary/teal + **Behandeln + Sicherheitsnetz**  
- SCOPE: square frame / hairline break; title = content label only („Grenze der eigenen Zuständigkeit“)  
- No unlabeled color bar as sole encoder  

## Branching / loop invariants

- No collapsing T1/T2

- T4 never „Treat ohne Netz“; known TIA/Schlaganfall history only after **ärztlicher Freigabe** aus der Akutphase  
- Default-to-Danger: Im Zweifel Notruf statt abwarten/mobilisieren (C)
