## Learner job (one primary)

**recognize**

**Primary job:** See distal regional CRPS *signal* (disproportional + allodynia + vegetative/trophic asymmetry) in one glance without mistaking it for a diagnosis stamp.

## Form intensity

- **Chosen level:** **L6** (pictorial / free vision) with **L4 code-cluster fallback**
- **Why not L−1 (L5 pure CeTZ only as first try):** recognition gestalt (shine, asymmetry, touch intolerance) is partially pictorial; free vision can dual-code better **if** denser than a pin-chip grid. Code densified cluster remains mandatory pin-safe fallback.
- **Why not only L3 chips:** chips alone restate the table; miss co-located distal regional picture that is the point of ambition.
- **Why not higher-than-needed anatomy L6:** full anatomy dissection is wrong job (rejected).

## Simple alternative

- [x] §3 four-domain table only  
- [ ] numbered cue list  
- [ ] library pin-swap  

**Why not only floor:** table teaches channels; ambition teaches **gestalt co-location** distal regional pattern under scan.

## Space budget

- **Teaching gain vs next-lower intensity:** **clear** (essential only if free vision actually denser than L4 chip grid — DC must re-check after realize)
- **Max vertical budget:** ☑ ~⅓ page (hard cap ½; sparse full-page = fail)
- **Why earned:** gestalt + 5–6 cue chips + side-compare + quiet safety brake
- **If gain ≤ weak → step down:** demote free PNG to harvest reference; ship **L4 code cluster** as winner (allowed Accept path)

## Form choice

- **Pattern name:** regional distal cue cluster (criteria-by-picture) + side-compare + safety brake
- **Intensity level:** L6 attempt / L4 floor
- **Media-design reason:** Dual coding schematic extremity + chips; contiguity of compare mark with color/temp asymmetry; segment 5–6 must-sees; density cap prevents hero sprawl.
- **Medical-pedagogy reason:** CRPS recognition in DA is pattern-based (disproportional pain + vegetative/trophic distal). PT must not wait for a Budapest checklist that C does not print. Safety brake prevents overclaim “this *is* CRPS”.

## Reading order

1. Distal extremity gestalt (hand-first default — Fall uses hand; foot OK if labeled)  
2. Loud chips: Disproportionalität · Allodynie  
3. Vegetative/trophic chips + side-compare  
4. Quiet safety brake (not diagnosis; Notfall-DDx first / Budapest ärztlich)

## Success criterion

Under 15 s scan: distal regional + allodynia + asymmetry visible; C-faithful safety brake present; ≤⅓–½ page; schematic/didactic style (not photoreal); claim audit maps every label to C; free vision not pin-monotone.  
**Density gate:** if free vision ≤ L4 code cluster clarity/density → ship **code cluster** as winner; free vision still required as process step.

## Risk of wrong form
