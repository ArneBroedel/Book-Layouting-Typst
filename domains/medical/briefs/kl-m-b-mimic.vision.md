## Learner / didactic intent

- **unit type:** comparison (error mode)
- **learner job:** distinguish — see false MSK/everyday frame masking real soft-tissue infection risk
- **load risk:** wireframe meta labels; reverse direction; equal 2×2 cells
- **presentation hypothesis:** mask/peel dual layer — peel away “harmless” label to reveal danger
- **success criterion:** Under scan stress learner maps each false frame to real danger with correct direction
- **why graphic:** error-mode must *feel* like unmasking, not a bullet list

## Must-see

1. Direction frame → danger (not reverse)
2. Four Erysipel maps (pins below)
3. No English stage titles; no UI words like “Label/Darunter”
4. German only on any visible text
