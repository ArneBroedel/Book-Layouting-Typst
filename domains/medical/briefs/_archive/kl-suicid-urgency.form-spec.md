## Cognitive / layout levers

- **Segmenting:** one block per TIME tier present (T1, T2, T4 only — **no T3 slot**)
- **Signaling:** weight T1 ≫ T2 ≫ T4 (size/fill/left bar + **label**, not color alone)
- **Contiguity:** trigger list adjacent to Handlung *inside* same tier
- **Nested multi-trigger:** all hard 112 triggers **inside** one T1 card
- **Figure–ground:** SCOPE frame optically outside TIME stack
- **Collapse:** omit T3 entirely (content has no „Zeitnah Arzt“ row)
- **De-drama:** T1 loud by **label + weight**, not sensational imagery; framework remains calm teal outside T1
