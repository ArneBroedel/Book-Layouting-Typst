## Learner context

- **Actor:** HP Physio
- **Time pressure / scan budget:** 10–15 s to structure examination attention
- **Setting:** first re-eval weeks after trauma/OP

## Learner job (one primary)

**recognize** (structure the look)

**Primary job:** Hold the **regional distal** pattern (disproportionaler Schmerz + vegetative/trophische Zeichen) as a coherent suspicion cluster across four channels — not a random symptom list.

## Load risks (if form is wrong)

- Flat four-row table with equal weight  
- Anatomy photo that freezes pipeline (H-Gfx pause)  
- Invented Budapest criteria not in C  
- Missing Allodynie / Seitenvergleich emphasis  

## Cognitive / layout levers

- dual coding (abstract regional “distal field” + channel labels)
- signaling (Untersuchung + Beobachtung louder)
- segmenting (4 channels)
- contiguity (signs clustered as one region, not scattered)

## Information architecture (zones)

| zone | loudness | content role | must feel like |
|---|---|---|---|
| Core claim strip | loud | disproportional + regional distal | one sentence cluster |
| Channel tiles | medium–loud | Anamnese · Beobachtung · Untersuchung · Verlauf | 4 equal ontology channels |
| Untersuchung emphasis | loud | Allodynie, Seitenvergleich, Pulse, Wunde | highlighted channel |
| Quiet note | quiet | no free diagnosis | not a tier |

## Must-see elements

1. Four channels with C features  
2. Disproportionaler Schmerz + Allodynie + vegetative/trophische Zeichen  
3. Distales, regionales Verteilungsmuster (as **text/geometry**, not limb photo)  
4. Verlauf: Tage–Wochen; Persistenz/Zunahme; Red-Flag re-triage if Fieber/Spannung/Pulslosigkeit  
5. German only; no form-meta

## Claim pins (German, copy-through C §3 + §4 erhärtet)

| zone | allowed text (German) |
|---|---|
| Core | disproportionaler Extremitätenschmerz nach Trauma/OP plus vegetative und/oder trophische Zeichen; distales, regionales Verteilungsmuster |
| Anamnese | Trauma/OP der Extremität; brennender, stechender oder dumpfer Schmerz **deutlich stärker als zur Verletzung passend**; Berührungsempfindlichkeit; Schwellung; Farb- oder Temperaturdifferenz; vermehrtes Schwitzen; motorische Unsicherheit |
| Beobachtung | Asymmetrische Schwellung; Hautfarbe blass, rötlich oder livide; sichtbare trophische Veränderungen (Haut, Nägel, Behaarung); Schonhaltung |

| Verlauf | Tage bis Wochen post Trauma; Persistenz oder Zunahme statt erwarteter Heilung; bei Fieber, eitriger Wunde, rascher Spannungszunahme oder Pulslosigkeit **sofortige** Notfall-Re-Triage |
