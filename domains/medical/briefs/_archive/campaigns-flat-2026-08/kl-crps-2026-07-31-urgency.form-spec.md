## Learner context

- **Actor:** HP Physio / PT Direktzugang in MSK Nachsorge
- **Time pressure / scan budget:** 10–25 s for tier choice
- **Setting:** Praxis / Hausbesuch post-Trauma/OP

## Learner job (one primary)

**choose** (+ **stop** on T1; **constrain** on SCOPE)

**Primary job in one sentence:** Assign the correct TIME tier for the CRPS-adjacent extremity picture, execute that tier’s action, and never treat medical SCOPE as a quieter urgency step.

## Simple alternative (required)

- boring default: **4-row markdown-style table** (Situation | Dringlichkeit | Handlung) as in C  
- why not only that: under scan stress T1 and T3 collapse into one “Arzt/Notfall” blob and SCOPE becomes a fifth table row that reads like T5; stack + orthogonal frame reduces that class of error

## Load risks (if form is wrong)

- T1 (vascular/compartment/infection) visually equals T3 (CRPS-Verdacht zeitnah)
- T2 and T1 merge into one red wall
- SCOPE reads as green “may treat” clearance under T4
- Multi-trigger T1 becomes three separate ladder rungs of urgency
- Solid-red full Master chrome (wrong genre)
- Empty loud 112 theater when learner only has CRPS-Verdacht without red flags

## Cognitive / layout levers

- **Segmenting:** one block per TIME tier (all four present in C)
- **Signaling:** weight T1 ≫ T2 ≫ T3 ≫ T4 (size/fill/left bar + **label**, not color alone)
- **Contiguity:** triggers adjacent to Handlung inside same tier
- **Figure–ground:** SCOPE frame optically outside TIME stack
- **Multi-trigger:** three T1 trigger groups inside **one** T1 card

## Information architecture (zones)

| zone | loudness | content role | must feel like |
|---|---|---|---|
| TIME stack T1→T4 | T1 loudest | urgency + action payload | ordered priority landscape |
| T1 internal | max | one stop card + 3 trigger groups | **one** 112 card, not three rungs |
| T2 | loud | same-day medical path | distinct from T1 and from T3 |
| T3 | medium | CRPS-Arbeitsverdacht → zeitnah Facharzt | the true CRPS path — not soft emergency |
| T4 | medium-quiet | treat + return net | permission with constraints |
| **SCOPE frame** | quiet-strong border | competence boundary | **not** a TIME tier (geometry); content title only |
| Quiet | quiet | sources later | not before action |

## Must-see elements

1. **T1 ≠ T2 ≠ T3** — separate labels and visual weight  
2. **Three T1 trigger groups** inside one card: art. Ischämie · frisches Kompartiment · Fieber/Eiter/Sepsis-Lage  
3. **T3 CRPS path** visible: disproportional + vegetative/trophische **ohne** Red-Flags → zeitnah Facharzt  
4. **T4 constraints:** only after DDx exclusion + specialist co-management; **keine** forcierte schmerzhafte Mobilisation; Rückkehrgründe  
5. **SCOPE:** Budapest · Ausschlussdiagnostik · Systemtherapie · endgültige DDx = ärztlich; PT screent/triagiert  
6. Genre: teal framework Master; solid danger only on T1

## Urgency / weight encoding

- T1: solid danger + bold **112** label  
- T2: warning/amber + **Notaufnahme / gleichtags**  
- T3: cool/info + **Zeitnah Facharzt** (CRPS-Verdacht)  
- T4: primary/teal + **Behandeln + Sicherheitsnetz**  
- SCOPE: different geometry (square frame / hairline break); title = content label only (`Grenze der eigenen Zuständigkeit`)

## Branching / loop invariants

- All four tiers present (C fills them) — do not invent extra tiers  
- Multi-trigger stays inside T1  
- ACTION inside tier only  
- No Treat-without-net  
- No form-meta captions (“keine Dringlichkeitsstufe”, ontology IDs)

## Claim pins (German, copy-through from C)

| step / zone | allowed text (German) |
|---|---|
| T1 label | 112 |
| T1 triggers | Akute Blässe, Pulslosigkeit, kalte Extremität (arterieller Gefäßnotfall); Spannungsblase, extreme Schwellung und Schmerz deutlich stärker als zur Verletzung passend frisch posttrauma (Kompartmentsyndrom); Fieber, eitrige Wunde oder systemische Infektzeichen mit drohender Sepsis |
| T1 action | Behandlung sofort abbrechen. Notfalltransport veranlassen. Übergabe mit Trauma-/OP-Kontext, Zeitverlauf und Red-Flag-Befunden |
| T2 label | Notaufnahme / gleichtags Arzt |
| T2 triggers | Starke, ausstrahlende oder progrediente Schmerzen mit systemischen Symptomen (Infektverdacht, Thromboseverdacht, drohendes Kompartiment) ohne unmittelbare 112-Lage; unklare akute Verschlechterung posttrauma |
| T2 action | Physiotherapie stoppen. Unverzüglich in die Notaufnahme einweisen oder gleichtags ärztlich abklären lassen. Keine forcierte Mobilisation |
| T3 label | Zeitnah Facharzt |
| T3 triggers | Disproportionierter Extremitätenschmerz plus vegetative oder trophische Zeichen nach Trauma/OP ohne Notfall-Red-Flags — Arbeitsverdacht CRPS |
| T3 action | Befunde dokumentieren (Seitenvergleich, Allodynie, Temperatur/Farbe, Trauma-Anamnese). Zeitnah der Schmerzmedizin, Neurologie oder Unfallchirurgie zuweisen. Budapest-Diagnose und Systemtherapie erfolgen ärztlich |
| T4 label | Behandeln mit Sicherheitsnetz |
| T4 condition | Nur nach Ausschluss von Notfall-DDx und bei laufender oder geplanter fachärztlicher Mitbetreuung; keine hochgradige Allodynie ohne interprofessionellen Plan |
| T4 action | Modifizierte, schmerzadaptierte Therapie. Keine forcierte schmerzhafte Mobilisation. Rückkehrgründe: Fieber, rasche Schwellung, Pulse/Farbe, progrediente Parese |
| SCOPE title | Grenze der eigenen Zuständigkeit |
| SCOPE body | Budapest-Diagnose, bildgebende/laborchemische Ausschlussdiagnostik, Systemtherapie (Medikamente, Interventionen), endgültige DDx Infekt/Kompartment/Ischämie/TVT — HP Physio screent und triagiert; stellt CRPS nicht abschließend fest und führt keine Systemtherapie durch |
