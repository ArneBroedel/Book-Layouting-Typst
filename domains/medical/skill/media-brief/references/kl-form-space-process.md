# KL form-space process (Media + handoff)

**Load when:** Starting or expanding Krankheitslehre visual language for a monograph or unit family.  
**Ontology first:** [`kl-illness-script-ontology.md`](kl-illness-script-ontology.md)

---

## Grammar first, then ambition

```text
1. Invariants hold (TIME/SCOPE, no form-meta, pins)
2. Band-grammar units (urgency, discrimination, mimic, cues…) → reliable code
3. Per chapter: ≥1 ambitious unit (spatial, peel, free vision) when it earns the job
```

Skipping (1) for “pretty” free vision → Phase-1-class fails.  
Stopping at (2) only → clean but uninspired (Human feedback).

---

## Pipeline (one monograph or form family)

| Step | Owner | Output |
|------|--------|--------|
| **R** Relation map | Media | Units + dimensions; prefer **content-map** file (`briefs/_wave5/<slug>.content-map.md` pattern) |
| **C** Form-Space | Media | ≥3 valuable + ≥2 rejected paths per *new* unit; shortlist |
| **M** Form Spec | Media | Gold density: zones, Must-see, pins, genre, success criterion; **Icon meaning** if criteria-by-picture |
| **G** Realize | Graphics | **track** (default free-vision-ambition) → free vision → **claim audit** → **harvest** → hierarchy-faithful recreate/hybrid/refine |
| **A** Accept | Media | accept/revise/reject + carrier + **free-vision proximity** on ambition track; exploration vs production |
| **O** Transfer | Media/Tech | Same recipe, new pins; re-audit free labels **and** icons |
| **h** Mini-harvest | Media/Graphics | New durable pattern → `kl-form-library.md` + recipe |

### Content-map (R) recommended shape

Deep analysis artifact before Form Specs (Wave-5 lesson):

```markdown
# Content map — <title> (R)
## What this chapter actually teaches
## Script units → ontology
## TIME matrix (pin-ready rows)
## SCOPE / discrimination / mimic / cues
## Distinctive form pressure vs library
## Ambition candidates + transfer recipes
## Success criterion
```

Do **not** open production compose without freeze + production Accept.

---

## Form-Space table shape (C)

```markdown
## U-<id>
### Relation / job / success criterion
### Wertvolle Pfade (≥3)
| id | name | why | graphic type | carrier | free-vision? |
### Verworfen (≥2)
### Shortlist → Form Spec
```

Hypotheses = prose names (e.g. `kl-urgency-scope-dashboard`), not catalog form ids.

---

## Creativity slot

Per chapter exploration: at least one unit with **high ambition** when pedagogically justified:

- spatial map · peel/mask · true flowchart · free vision dashboard · **criteria-by-picture** (ABCDE-style)  

Document in wishlist; do not invent clinical content for drama.

### Form Spec add-on when free vision draws criteria

If icons will *show* clinical meaning (not only caption it), add under Must-see or a short **Icon meaning** list:

```markdown
| pin / zone | what the drawing must show (not only the text) |
|---|---|
| B unscharfe Begrenzung | soft/feathered edge; not hard zigzag |
| D typisch > 5 mm | object visibly larger than a 5 mm reference |
```

Graphics claim audit checks this; Human review is high-value here.

## Transfer hygiene (O)

| Do | Don't |
|----|--------|
| Swap claim pins into grammar modules | Copy Erysipel clinical text |
| Reuse TIME/SCOPE geometry | Reuse unlabeled decorative bars from another disease |
| Exception-T1 when C de-emphasizes 112 | Fake loud empty 112 wall |
| Free vision for new ambition units | Force every unit into the same Erysipel stack look |

---

## Anti-process

| Avoid | Do |
|-------|-----|
| Typst variants before Form-Space | Relation → paths → Spec |
| 50 parallel monographs | Grammar transfer + few ambition pilots |
| Content rewrite here | Pins only; Author Qs to C |
| Accept monotony because compile green | Accept rubric + wishlist honesty |
| Accept free vision on labels only (icon units) | Labels + illustration-semantics (+ Human on icons) |
