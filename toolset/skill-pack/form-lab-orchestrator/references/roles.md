# Roles — Form Lab

## OR — Form-Lab Orchestrator (this skill)

| Does | Does not |
|---|---|
| Board, run-log, route, budgets | Rewrite clinical content |
| Freeze pins + lab-id / portfolio scaffold | Skip min craft rounds or PNG eyes |
| Emit HAND-OFF packets as **durable state** | Stop after L0 handoff under **default L2** |
| **Under L2:** execute PW/PC/CM/SY procedures in-session | One-shot craft without critique artifacts |
| Enforce medium allow/deny on status checks | Mix two media in one pass mandate |
| Drive comparison → S best-of → harvest | Synthesize before matrix; skip L7 |
| Stop on caps, errors, non-waived Human gates | Pretend one-shot is optimum |

**Route-only opt-out:** OR does not craft; only routes external workers.

## PW — Pass Worker (Builder)

Implements one pass under medium rules. Loop: build → PNG → accept critique → revise.

Under L2, OR **acts as** PW for the current pass while keeping PC as a separate step/artifact.

Must not: mark medium-optimum alone without PC artifact; switch medium mid-pass; invent claims.

## PC — Pass Critic

Reads **latest PNGs** + medium-rules. Writes `critique-rNN.md` with blocks/nits and concrete fixes.

Attack dimensions: medium purity, learner jobs, scan path, craft ceiling, claim honesty, density, **Semantic Read**.

Must not: implement fixes as the only voice without a Builder step; soften FAIL to ship.

## CM — Comparator

After all optima: fill matrix jobs × passes from PNG sets. Caption-free teaching scores. FAIL cannot win. Record winner **asset paths** for S.

## SY — Synthesizer (Pass S best-of)

Build Pass S from matrix winners / Human rank using **prepared assets** from this lab’s T/C/V/R. Omit weak media. One primary mark per job. Iterate to synthesis-clean.

Must not: invent untested media; mount SR FAIL; force C+T+V+R on page 1.

## H — Human

Kickoff D1–D8; optional H-Pass; optional S-rank (waivable under autodrive). Does not receive one-shot drafts as lab complete.

## Quorum

**Medium-optimum** requires:

1. `craft_round >= min_craft_rounds`  
2. PC status medium-optimum-candidate with empty block list  
3. No open SR FAIL on mounted teaching marks  
4. Exhaustion dossier written  
5. OR records pass optimum (or Human H-Pass)  
6. Latest PNG set linked (not stale)

**Synthesis-clean (S)** requires: matrix-backed carriers, SR PASS mounts, omit-is-win applied, iterative critique empty of blocks, coherent scan path.

Builder ≠ sole Critic on the same artifact version without an explicit Critic step artifact.
