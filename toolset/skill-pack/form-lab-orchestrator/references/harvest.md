# Harvest (L7) — hard gate for COMPLETE

## Why

Craft PDFs and Pass S alone do not improve the production pipeline vocabulary. Harvest turns matrix + S evidence into:

1. **form-vocabulary** — shared language for job classes × media  
2. **production-bridge** — defaults and do-nots for compose / medical-graphics later  

Without harvest, Form Lab is expensive theater.

## Required deliverables

| File | Template | Minimum content |
|---|---|---|
| `form-vocabulary.md` | `_templates/form-vocabulary.md` | Job classes table + medium strengths + anti-collapse rules grounded in **this** lab/wave |
| `production-bridge.md` | `_templates/production-bridge.md` | Job→carrier defaults table + anti-patterns citing concrete labs/media |

Optional: `human-s-rank.md`, `sr-log.md`.

## Location

Prefer **portfolio-level** when multiple labs share a wave:

```text
toolset/orchestration/form-lab/portfolio-<wave>/harvest/
  form-vocabulary.md
  production-bridge.md
```

Per-lab `…/<lab-id>/harvest/` is fine for a single-lab run.

## Process (no re-craft)

1. Read all `comparison/matrix.md` for the wave/labs.  
2. Optionally skim Pass S notes / dist winners (do not recompile unless checking evidence).  
3. Fill vocabulary job classes from winner columns.  
4. Fill production-bridge defaults + do-nots (SR FAIL demotions, caption-dependent clocks, rainbow chips, forced collages, …).  
5. Set board `harvest=done`; portfolio board notes harvest complete.  
6. Log run-log entry `L7 harvest DONE`.

## COMPLETE rules

| State | Allowed? |
|---|---|
| Craft done + harvest done | **COMPLETE** |
| Craft done + harvest waived with board text | **COMPLETE-with-waiver** |
| Craft done + harvest silent/todo | **not COMPLETE** (post skill establishment) |
| PDF only | **not COMPLETE** |

Legacy a/b boards: leave historical COMPLETE; do not mass-rewrite.

## What harvest is not

- Not Media Accept  
- Not production free-vision budget raise  
- Not a new Guide unless vocabulary stabilizes (optional later)  
- Not skill-creator full eval suite (optional)
