# Multi-chapter exploration portfolio (ops)

**Source:** `devtracks/multi-chapter-explore-layout/` · board e.g. `kursbuch-explore-2026-08`  
**When:** `brief_class: exploration`, curated N chapters, L2/L3 drive.

## Charter (L2)

| Stop | Do not stop |
|---|---|
| H-Design, H-Gfx, caps, hard error | After one chapter “for Human chat” while rows remain `todo` |
| Documented hard H-Explore (if kickoff set it) | Soft “wave feels done” without board idle |
| **Portfolio idle** (all locked rows accept+compose+pdf) | Chat-length fatigue |

**Agent-only H-Explore (D4):** agent enforces Design+Visual CLEAN; Human may sample anytime; **not** a default per-chapter pause.

## Per-chapter tick (skills, not improvised)

```text
content-map → media-brief (Form Spec + Contract + DC CLEAN)
  → medical-graphics (track per unit) → VC CLEAN on full chapter PNGs
  → Accept exploration → compose-chapter → bookkit validate
  → board + run-log + route
```

Pipeline detail: track `phase2-wave-execution.md`.

## Free vision selectivity (portfolio reality 2026-08)

| Unit class | Default |
|---|---|
| Urgency / mimic / discrimination (grammar known) | **code** + optional free if Media marks ambition |
| Spatial criteria without anatomy job | **code panel** (Kompartment pattern) |
| FAST / letter criteria densified | **code densified** preferred |
| True gestalt recognition (e.g. hot mono) | free **or** hybrid; default no labels in raster |
| Anatomy / body cut | **paused** without H-Gfx |

Document every free **skip** in brief/Form Spec (grammar-only opt-in).  
Do **not** silent chapter-wide grammar-only.

## SCORE / CERTAINTY hygiene (KL)

Wells, YEARS, ABCD², Marburger Herz-Score, etc. are **SCOPE / sensibilization** — never a TIME ladder step or “rule-out” green tier.  
See `media-brief/references/kl-illness-script-ontology.md` (CERTAINTY).

## T3 collapse

If C has no zeitnah tier → **no empty T3 slot** and no invented T3. Stack only filled tiers (ACS, LE, Stroke, MI patterns).

## Parallel workers

Allowed for throughput **if**:

1. Each child produces full skill packets (brief → accept → pilot PDF)  
2. Parent **reconciles board** before claiming idle  
3. Parent (or serial pass) re-checks **macro scan-path + print density** on composed chapter PNGs  

Workers often miss page-level sparse-sprawl and restless structure.

## Chapter done checklist (orchestrator)

- [ ] Design CLEAN + Visual CLEAN (macro scan-path + density)  
- [ ] Accept exploration; quality packet  
- [ ] `dist/pilots/<slug>/chapter.pdf` + PNGs  
- [ ] `bookkit validate` OK  
- [ ] Board cells + portfolio row updated  
- [ ] No production compose claim
