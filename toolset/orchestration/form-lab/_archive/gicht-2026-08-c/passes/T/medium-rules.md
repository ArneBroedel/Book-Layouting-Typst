# Medium rules — Pass T (Typography + Icons)

## Goal

Maximum learning effect and readability using **only** fundamental typographic hierarchy plus simple, repeatable icons.

## Allow

- Type scale, weight, optical hierarchy, running heads
- Lists, definition runs, tight tables
- Simple monochrome / one-accent icons (FA or custom 1-color glyphs) as **recurring marks**
- One quiet danger/emphasis line (rule or short bold line — not a card wall)
- Purposeful whitespace; multi-column only if scan improves
- Semantic **weight** and **size** (not fill panels) for urgency cues where possible

## Deny

- Multi-color filled card stacks as primary structure
- TIME as four solid colored slabs (→ Pass C)
- Free-vision / photo / rich multi-tone SVG scenes
- Decorative gradients, blob geometry
- “Looks designed” chrome without type role

## Exhaustion signal

Further real gains would require area color, illustration, or relational diagrams — document in `exhaustion.md`.
