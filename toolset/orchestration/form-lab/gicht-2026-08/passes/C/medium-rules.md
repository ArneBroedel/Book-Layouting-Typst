# Medium rules — Pass C (Color / Chrome / simple forms)

## Goal

Maximum scan hierarchy and didactic structure with **color, surfaces, shapes, and simple layout tools** — comprehensive use of the chrome toolset, still without rich illustration systems.

## Allow

- Semantic color, left bars, bands, cards, grids  
- TIME stack, mimic frame→danger rows, FA/NM panels  
- Shape/weight hierarchy; solid shout only for rare max attention  
- Bookkit / explore chrome primitives  
- Quiet tables and chip rows  

## Deny

- Free-vision photos / raster heroes as main teaching (→ Pass R)  
- Large custom multi-illustration SVG systems (→ Pass V)  
- Pure type-only pages that refuse all useful chrome (that was Pass T)  
- Meaningless rainbow fills  
- **Chrome that confuses clinical meaning** (e.g. five rainbow ABCDE letter cards as if **C = Color** meant UI hues — clinical pigment variety belongs in a lesion depiction or plain text; letter hierarchy should be quiet / same-family or type weight)

## Exhaustion signal

Remaining weak jobs need *picture* or *vector schema*, not another box variant.
