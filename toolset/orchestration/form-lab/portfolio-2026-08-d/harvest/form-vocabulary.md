## 2. Medium strengths (wave-d)

| Pass | Wins when… | Residual / fails when… | Labs |

| **T** | Transfer lists, biphasic prose, mimic enums, quiet criteria | Hot recognition without picture | gicht mimic co; melanom mimics; anaphylaxie biphasic/boundary |
| **C** | Urgency hierarchy, danger bands, TIME ladder, peel rows, role frames | Photoreal gestalt | **all four** for danger/TIME |
| **V** | Schema when photo absent; ban glyphs if legible | Caption-only doodles; loses to strong R | all V optima reached, but **S consistently omitted V** when R covered recognition |
| **R** | In-situ recognition (one primary per job); case anchor | Triage chrome; speech grimace FAIL risk; weak biphasic still-life | all four; speech **never mounted** (schlaganfall) |
| **S** | Proven winners only; omit weak media | Forced multi-medium collage | all S: **omit V** (omit-is-win) |

```text
S ≈ C(danger + TIME + peels) + R(recognition + case) + T(mimic/biphasic residual)
V omitted when R SR PASS covers gestalt
```

This is stronger and more consistent in wave-d than wave-c (where V still won some ban/FAST letter jobs in S).

## 4. Anti-collapse rules (keep from wave-d)

1. **Omit is a win** — all four S packages **omitted V** for recognition; schlaganfall never mounted speech raster.  
2. **Caption-free teaching** — matrix scores without reading caption.  
3. **Semantic Read hard gate** — FAIL cannot win; speech grimace pre-emptively omitted.  
4. **One primary mark per learner job** — no face+face stack.  
5. **No rainbow ABCDE letter chips** — melanom C quiet chrome; R photo row for criteria.  
6. **Clean restart:** no a/b/c pilot/asset/dist reuse; new gens only after SR PASS.  
7. **Boundary often R photo** when gesture/scene is clear (gicht X-hands; schlaganfall ban HWS) — else T/C type.
