# Medium rules — Pass S (Synthesis / best-of fusion)

## Goal

**Best overall chapter for the learner** by **fusing proven winners and prepared assets** from T/C/V/R — the mandatory lab product under form-lab autodrive, not an optional demo and not a collage that forces every medium onto the page.

## Allow

- Forms and aspects that appear as matrix **winners / co-winners** with **Semantic Read PASS**  
- Mixing e.g. T body + C urgency chrome + **one** strong R recognition set  
- **Omit is a win:** drop an entire medium if it does not beat type for any job  
- One primary teaching image per learner job (strongest only)  

## Deny

- New untested media not exercised in T/C/V/R(/D)  
- Reintroducing portfolio monotony by habit  
- Mounting Semantic Read **FAIL** aspects/glyphs (including “we’ll explain in caption”)  
- Stacking redundant marks for the same job (face photo + grimace + face-glyph)  
- Force-including Pass V doodles because V was co-winner on paper while R already teaches the job  
- Layout quotas (“must show C+T+V+R on page 1”)  

## Synthesis procedure (mandatory)

SoT: `domains/medical/skill/medical-graphics/references/prompt-and-semantic-read.md` §§2–4

```text
1. Read comparison/matrix.md winners (PASS only).
2. Per learner job: pick the single strongest teaching carrier.
3. Ask crop-test: hide all German text — does the visual still teach?
   No → drop visual; use type/chrome for that job.
4. Build S chapter from survivors only.
5. Export PNGs → full Semantic Read on every mounted teaching mark.
6. Craft rounds: coherence + density + scan — never reintroduce FAIL glyphs.
```

## Exhaustion signal

Further mixing only reshuffles; residual is content/claim limit, not missing doodles.
