# Spec — KL Form Language (Illness Script presentation system)

## Problem

Krankheitslehre monographs (88+ in Welle-06) need a **reusable, relation-true, creative** presentation language for Direktzugang teaching. Exploration produced ontology, form-space, Typst modules, free-vision spatials — knowledge was scattered in `_explorations/` and spikes.

## Goal

1. **Normative** agent/human access via skills + guides (harvested).  
2. **Library** of transferable recipes (urgency/scope, mimic, discrimination, mechanism, spatial).  
3. **Operating model** for more chapters: pin-transfer + creativity slot + mini-harvest of new patterns.  
4. No medical genre logic in `packages/bookkit` foundation; Content C remains SoT for claims.

## Non-goals

- Rewriting manuscript content/templates in this repo  
- Production print of full Kursbuch without freeze/Accept  
- Replacing III/IV action cards with V master layouts  

## Success

- Agent loads ontology + form library in ≤2 hops from skill  
- New kl-kurz can reuse §5/§4/mimic modules with new pins  
- Form-meta anti-pattern does not reappear  
- Exploration remains provenance-only
